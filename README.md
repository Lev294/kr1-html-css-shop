# ShopProject — компьютерные аксессуары

Магазин из КР №1, обновлённый для практик №12–15. Автор — Демидовс Лев Алексейсович, группа ЭФБО-05-25.

[Открыть магазин на GitHub Pages](https://lev294.github.io/kr1-html-css-shop/)

В каталоге девять товаров. У каждой модели есть страница с описанием, ценой и характеристиками. В общем меню три раздела — «Главная», «Каталог» и «О магазине и контакты». Кнопка «Заявка» в шапке открывает отдельную страницу. На странице о магазине есть телефон, часы работы, почта и форма обратной связи. Товары и контактные данные демонстрационные.

## Запуск с Go

Нужны Node.js 22.12 или новее и Go 1.22 или новее. Из корня проекта:

```sh
npm ci
npm run build
go run ./backend
```

Откройте [магазин на localhost](http://127.0.0.1:8080/). Go отдаёт сборку из `dist`, каталог и API форм с одного адреса. Для разработки интерфейса запустите отдельно `npm run dev`. Vite перенаправит запросы `/api` на локальный Go-сервер.

GitHub Pages публикует статическую сборку React. На опубликованном сайте можно открыть все страницы, поискать товары и проверить валидацию формы. Для сохранения заявок используется локальная версия с Go.

## Как работает проект

**React и SEO.** Vite собирает клиентские файлы и модуль для серверного рендеринга. Скрипт сборки один раз вызывает `renderToString` для каждой страницы и записывает готовый HTML. Содержимое, заголовки и ссылки доступны до загрузки JavaScript. Браузер вызывает `hydrateRoot` и подключает к этому HTML события React. Модульный `script` выполняется после разбора документа, как отложенный скрипт.

Сборка формирует главную, каталог, страницу о магазине, заявку и девять страниц товаров. `product.html` открывает K-87. Адрес `keyboards.html` перенаправляет на вкладку клавиатур в каталоге. Адрес `contacts.html` открывает раздел контактов на `about.html`. Ссылки в HTML позволяют переходить между страницами напрямую.

Карта сайта доступна по адресу [sitemap.xml](https://lev294.github.io/kr1-html-css-shop/sitemap.xml). Форма заявки и страница 404 имеют `noindex`, поэтому их нет в карте. Готовый `robots.txt` действует при размещении на корне домена. Подкаталог проекта на GitHub Pages не управляет `robots.txt` для всего домена. Для размещения на другом адресе задайте `SITE_URL` при сборке.

**Адаптивность.** Базовые стили рассчитаны на телефон. Медиазапросы `min-width` меняют число колонок, положение категорий и компоновку формы. Для фотографии на главной `picture`, `srcset` и `sizes` позволяют браузеру выбрать подходящий WebP. У иллюстраций товаров сохранились пропорции, конкретные `alt` и заданные размеры.

**Вкладки и поиск.** На главной можно переключать советы для учёбы, работы и игр. В каталоге вкладка задаёт категорию, а строка поиска фильтрует её по названию, описанию и характеристикам. В `TextInput` лупа передаётся через `startIcon`, поэтому компонент сам выделяет ей место перед текстом.

**Доступность.** Ссылка пропуска переводит фокус в `main`. У полей есть связанные `label`, а у ошибочного поля — `aria-invalid` и ссылка на сообщение. Вкладки сообщают выбранное состояние через `aria-selected`. Быстрая заявка открывается нативным `dialog` и закрывается по Escape.

**Скидка и безопасный вывод.** Функции в `js/data.js` работают с объектом товара. Например, у K-87 исходная цена 5 000 ₽, скидка 2% и итог 4 900 ₽. Откройте `product.html?practice=15`, чтобы увидеть результаты функций в консоли и краткое описание на странице через `textContent`. В React данные из формы и ответы API выводятся текстом.

**Go.** Обе части проекта используют один каталог `data/products.json`. React отправляет форму через `fetch`. Go проверяет данные и согласие, сам вычисляет цену из каталога и возвращает номер только после записи файла. Каждый JSON лежит в отдельном файле, поэтому параллельные заявки записываются независимо. Хранилище по умолчанию находится в `var/orders/` и `var/messages/` за пределами публикуемого `dist`.

| Метод и путь | Результат |
| --- | --- |
| `GET /api/products` | Все девять товаров |
| `GET /api/products/K-87` | Данные одной модели или 404 |
| `POST /api/orders` | Валидация, сохранение заявки, номер и рассчитанная стоимость |
| `POST /api/messages` | Валидация, сохранение сообщения и его номер |

Ошибки полей возвращаются с HTTP 422 и именем поля, корректное обращение — с HTTP 201. Путь хранилища можно изменить параметром `-data`, а адрес запуска — параметром `-addr`.

## Проверки

В браузере проверены 13 страниц магазина при размерах окна **360 × 800**, **1440 × 900** и **1920 × 1080**. Ширина страниц укладывается в окно. При 1920 × 1080 главная занимает 3,1 экрана, каталог — 3,4, страница о магазине — 2,1, заявка — 2,1. Каждая страница товара занимает более двух экранов. Проверены вкладки, поиск, перенаправления старых адресов и автоматический выбор товара в заявке.

На локальном Go-сервере проверены отправка заявки с тестовыми данными и расчёт стоимости. `npm run build` и `go test ./...` выполнились успешно.

## Структура

```text
index.html           шаблон страниц
js/                  React-компоненты, маршруты и функции товаров
css/                 оформление и мобильная раскладка
data/products.json   каталог для React и Go
backend/             HTTP-сервер и обработчики форм
scripts/             формирование HTML и SEO при сборке
public/              изображения и favicon
lighthouse/          сохранённые отчёты
```

Практики №1–8 и исходная HTML/CSS-реализация доступны в истории репозитория. Практики №12–15 продолжены в этом же репозитории по указанию пользователя.
